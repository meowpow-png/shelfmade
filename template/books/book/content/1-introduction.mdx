# Introduction

Welcome to your new book. Every `.mdx` file in `content/` is a chapter, ordered by the number at the start of its name. Add `2-next-chapter.mdx` to start the next one.

<Note>
  This box is the `Note` component from `components/Note.tsx`. Components are registered in
  `book.config.ts` and styled in `style.css`, like the rest of the book.
</Note>

Run `npm run pdf` to print the book to `dist/`.
